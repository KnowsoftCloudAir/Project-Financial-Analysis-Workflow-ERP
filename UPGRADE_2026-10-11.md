# Upgrade package – 11 Oct 2026

## Fixed / restored

1. **Inventory (`/ops/inventory`)**
   - Central warehouse first, then kiosks, then PHCs.
   - Columns: Opening, Received (procurement), Dispatched (with facility codes), Returned, Balance.
   - Facility sheets: Received from central, Administered (uptake), Transferred, Returned to central, Balance.
   - System summary table (monthly administered projections).
   - Non-editable position sheets.

2. **Client assigned list (`/ops/uptake/clients`)**
   - Fixed authorisation and facility filtering.
   - Facility staff see only their clients; managers see all.

3. **Learning dashboard + H / LQ1–LQ11**
   - Routes already registered via `learning_data.py` (`/learning`, forms, analysis, Excel/PPTX export).
   - Restored registration path in `server.py`.

4. **Ambassador referral + Client feedback**
   - Ambassador concept already present in client feedback forms/dashboard.
   - Public feedback link remains at `/client-feedback` (also linked from nav / home).
   - Feedback feeds learning / manager views.

5. **New RFQ workflow (`/ops/rfq`)** – full chain restored via `workflow_upgrade.py`
   - Create RFQ with up to 10+ expandable catalog lines, units, optional price, conditions, TOR upload.
   - Flows to Program Manager for approval.
   - Create vendor-specific or general links (special number generated).
   - Vendor fills prices, uploads PDF invoice, submits.
   - Committee scoring links (technical + finance); scores aggregated.
   - Award → winner accept/reject → invoice → ready for GRN / inventory / accounting.
   - Accounting intent: Debit Central Warehouse Inventory / Credit AP on GRN; later cash payment via finance books.

6. **Cash reconciliation (`/ops/cash-recon`)**
   - Fully restored working page (statement vs book, tick lines, save history).
   - `/ops/bank` redirects here.

## How to run

```bash
pip install -r requirements.txt
python server.py
# or: gunicorn wsgi:application
```

Open http://127.0.0.1:5000

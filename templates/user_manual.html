1. Overview

What this application is for

The system supports the Benin City contraceptive service programme: planning budget, buying goods/services, receiving stock, dispatching to kiosks/PHCs, recording uptake, learning data, and financial control (codes, expenses, cash reconciliation, statements).

Data flows one way where possible: Budget → RFQ → Award → GRN → Warehouse → Dispatch → Facility → Uptake, with accounting entries posted at key hand-offs.

2. Roles & access

Who uses which parts

General Admin Project Manager (PM) Finance Admin / Analyst Programme / Logistics Committee member Vendor (public links only) Facility provider

  • PM — approves RFQs, awards contracts, final expense approval, learning oversight.
  • Finance — chart of accounts, project/expense/budget codes, expenses review, cash recon, statements.
  • Procurement / logistics — raise RFQ, vendor links, GRN, dispatch, inventory sheets.
  • Vendors — open private link only (no app menu); submit quote or accept award.
  • Facility staff — uptake, assigned clients, limited inventory view.

4. Finance setup

Codes (create → edit → use)
  1. 1 Chart of accounts — /finance/coa — account codes (Asset, Expense, Cash, etc.).
  2. 2 Project codes — /finance/projects — e.g. PRJ-FP.
  3. 3 Expense codes — /finance/expense-codes — each links one project + one account.
  4. 4 Budget codes — /finance/budget-codes — each links an expense code (project follows) + amount and dates.

Rule: new codes can always be added. Codes can be edited anytime. Delete only if unused; if linked to transactions, the system deactivates instead of hard-delete.

5. Budget template (Benin PLAN)

Path: /ops/budget-template

Shows budget lines in the Benin PLAN layout: Category, Operation title, Pilot (Apr 2026–27), Full scale (Apr 2027–28), TOTAL, Comments, PO, Supplier, Email, dates, Payment status, Packaging.

  • Lines come from Finance → Budget codes (codes like 3.1.1 group under Staff, Consultants, Services, Goods…).
  • Edit pilot / scale / total / comments / procurement fields → Save all edits.
  • Download Excel exports the same columns as the PLAN workbook.

11. Quick start checklist

First-time programme setup
  1. Create COA → Projects → Expense codes → Budget codes.
  2. Register products (Admin → Products) and facilities (warehouse, kiosks, PHCs).
  3. Register vendors (ERP → Vendors).
  4. Raise RFQ with catalogue lines + TOR → PM approves → Create vendor link.
  5. Receive bids → evaluate → recommend → PM award → Share → vendor accepts.
  6. Post GRN → warehouse stock → dispatch → uptake.
  7. Reconcile cash → review statements → check dashboard KPIs.

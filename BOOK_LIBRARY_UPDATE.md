# Churchgate Book Library update

## Member flow
Kwealth -> Book Library -> clickable 3D shelf book -> Reading Room/settings.

## Library
- Knowsoft Books: server/admin books only.
- Personal Books: member-uploaded books only.
- No separate default/sample book is displayed.
- Personal upload: PDF, TXT, DOCX.
- Maximum: 3 personal books total.
- Maximum: 4 MB per book.
- Users are advised to remove pictures/images before uploading for easier/faster upload.

## Reader
Each selected book opens through `?book_id=` and exposes the reading controls already provided by the Churchgate reader. Visible navigation returns to Book Library or Kwealth.

## Dashboard clock
The Knowsoft clock is persistent and uses the device's local JavaScript Date/time. It is fixed above dashboard layers with a very high z-index and remains draggable.

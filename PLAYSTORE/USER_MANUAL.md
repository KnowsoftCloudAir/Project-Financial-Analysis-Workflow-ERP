# Churchgate user manual (Play / web)

## Install
- **Play Store:** search Churchgate by Knowsoft (when published) or open the store listing.
- **Web:** https://onechurchgate1.onrender.com/
- **Windows / APK:** links published by Knowsoft Consult LTD.

## Create an account
1. Register with email (and phone if you want SMS codes).
2. Enter the confirmation code sent by email or SMS when that service is switched on.
3. Wait for church / admin approval if your assembly requires it.
4. Sign in. You may change your password after first login. Password change also uses a confirmation code when email/SMS is configured.

## Member dashboard
- Invite & earn (if enabled)
- **Memories** — upload photos, tap a picture or Play slideshow; choose music
- Kwealth books, hymns, notes
- Angel (voice)

## Books (Kwealth)
- **Library (Admin)** vs **My uploads**
- Load PDF or text; PDF is converted to readable text
- Read / listen. Choose language: English, French, Chinese, Spanish, Italian, German, Russian (uses device voices for that language when installed)
- Voice skips symbols and does not say “open parenthesis”
- Full screen + animation + optional background music
- Angel: “last book” / “continue reading” opens last book full screen with music

## Angel
Say “Angel” to wake.
Examples:
- last book / continue reading
- open Facebook / stream TikTok
- status, pastor message, play music
- Angel stop

Angel does not read punctuation names or recite a command list unless you ask “help”.

Project Financial Management Workflow — quick guide for staff.

← Dashboard
Use the left sidebar for day-to-day work. This page summarises the main flows. Paths below work after you are signed in.

  • Sign in with the email and temporary password from your administrator.
  • Change your password after first login if prompted.
  • Your role controls what you can open (admin, project manager, finance, facility/provider, consultants).
  • Workspace: /staff · Executive dashboard: /dashboard

Section hub: /ops/sections/program-core

  • Learning data — /learning: Headline (H) and LQ1–LQ11 forms, analysis, Excel/PPT export.
  • Assign staff (PM / program / general admin) — /learning/assign
  • Homepage & branding — /admin/homepage, /admin/branding
  • Sample data — /admin/sample-data (admins)

Section hub: /ops/sections/program-items

  1. Catalogue / products — /ops/catalogue, /admin/products
  2. GRN (goods into main warehouse) — /ops/grn
  3. Dispatch warehouse → facility — /ops/dispatch
  4. Inventory sheets (view / export) — /ops/inventory
  5. Uptake (client encounters / stock out) — /ops/uptake

Typical flow: Procurement / GRN → Dispatch → Facility confirms → Uptake reduces outlet stock.

Section hub: /ops/sections/procurement

  • RFQ workflow — /ops/rfq: create RFQ → program approval → vendor links → committee scores → award → invoice.
  • Procurement desk (vendor REF) — /ops/procurement
  • ERP — RFQs /erp/rfqs, vendors /erp/vendors, POs /erp/pos, invoices /erp/invoices

Section hub: /ops/sections/finance

Setup order: chart of accounts → projects → expense codes → budget codes.

  • COA — /finance/coa
  • Projects / expense / budget codes — under /finance
  • Journals, trial balance, statements, variance — finance menu
  • Bank / cash recon — /ops/bank, /ops/cash-recon

Payment chain: submitted → program approved → finance approved → paid. Finance approval posts expense / AP; payment posts cash.

Section hub: /ops/sections/staff

  • Privileges matrix — /ops/privileges
  • Users — /admin/users
  • Staff approvals — /admin/staff-approvals
  • Activity log — /admin/activity

  • Use the browser Back button or open Dashboard / My workspace.
  • Sign out and sign in again if the session looks stuck.
  • Admins: check Backup and restore before major changes.
  • Report the exact URL and the short error text shown on the red/green error panel to your administrator.

This in-app guide matches the current navigation. Detailed finance setup is also described in the project’s FINANCE_SETUP.md on GitHub.
